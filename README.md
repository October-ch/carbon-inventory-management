# 企業碳盤查數據管理工具

## Streamlit：底稿與報告連動原型

這個版本以左側計算底稿、右側互動報告呈現。報告章節參考經濟部《114 年溫室氣體盤查報告書》，改寫為虛構企業案例；所有活動量與係數均為模擬值。

### 參考文件與授權

專案附有經濟部《114 年溫室氣體盤查報告書》作為章節結構參考。該文件由經濟部網站提供，依經濟部政府網站資料開放宣告採用政府資料開放授權條款第 1 版；此專案保留原始 PDF，未修改其內容。

> 資料提供機關：經濟部，2026，《114 年溫室氣體盤查報告書》。本資料依政府資料開放授權條款第 1 版提供；使用時請遵守該條款。<https://data.gov.tw/license>

來源頁面：[經濟部內部溫室氣體盤查](https://www.moea.gov.tw/MNS/populace/content/Content2.aspx?menu_id=44746)；[經濟部政府網站資料開放宣告](https://www.moea.gov.tw/MNS/populace/content/ContentFoot.aspx?menu_id=13863)。

介面側欄可切換繁體中文與 English。英文模式包含工作區、主要操作頁籤、報告草稿、覆核欄位與英文 PDF 輸出；兩種語言的報告敘述分開保存。底稿原始 Excel/CSV 欄位仍維持中文，以保留來源檔欄位及追溯一致性，工作台會將示範項目名稱顯示為英文。英文報告以 2025 顯示民國 114 年，適合展示與討論，正式使用前仍需由具盤查知識的人員確認術語和適用規範。

### 啟動

已建立本機 `.venv`，可雙擊 `啟動Streamlit.command`，或在終端機執行：

```sh
cd 企業碳盤數據管理工具
.venv/bin/python -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8501
```

使用現有瀏覽器開啟 <http://127.0.0.1:8501>。服務只綁定本機位址；不需要瀏覽器自動化工具。若另一個執行中的程式已占用 8501，可先關閉原服務，或自行更改 `--server.port`。

若在新環境安裝：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

### 資料模擬練習入口

「資料模擬練習」頁預留 CSV → pandas → SQLite／SQL → 標準底稿 → 報告的串接位置，提供目標底稿欄位範本下載。目前尚未實作資料處理或匯入；後續練習將獨立建立。

### 操作

- 點擊右側藍色數值：左側自動切換工作表、捲動到對應列，並顯示公式、來源憑證編號及係數版本。
- 點擊總量或占比：標示全部參與計算的列；上方來源標籤可切換跨工作表來源。
- 點擊底稿任一列：檢視該列的來源、分類、完整單位及計算式。
- 雙擊活動量或係數，輸入後按 Enter：以 Python Decimal 重算報告內文、表格、占比與頂端合計；按 Escape 取消。
- 「原始 PDF 範本」頁籤：直接捲動連續閱讀原始 PDF，不需要選擇頁碼。原始 PDF 內容未綁定模擬底稿。
- 「匯出與修訂紀錄」頁籤：下載底稿 CSV、追溯快照 JSON 或報告 HTML，查看本次工作階段的修訂紀錄。

### 人工確認步驟

1. 首次載入應顯示總量 **447.141 tCO₂e**；直接排放 **7.406**、輸入能源 **439.309**、部分運輸 **0.426**。
2. 在報告摘要點擊輸入能源的 **439.309**：左側應切到用電底稿，12 筆來源列呈藍色。
3. 點擊右側「數據明細」，找到用電 114/12 活動量 **68,800.00**：左側應捲動到 `ELE-12`，標示活動量欄。
4. 切換到燃料工作表，再點擊報告中的用電數字：左側應自動回到對應用電列。
5. 在左側用電 `ELE-01` 的活動量上雙擊，把 **68,000** 改為 **69,000**，按 Enter；總量應變為 **447.611**，用電排放應變為 **439.779**。
6. 至匯出頁查看修訂紀錄與下載快照。需要回復時使用「重新載入初始模擬資料」。

### Excel → 報告編輯 → 覆核 → PDF

保留原有左右連動工作台，新增「Excel 匯入」、「報告編輯與覆核」及「PDF 預覽與輸出」頁籤。

1. 至「Excel 匯入」下載 v1 或 v2，將原檔上傳，再按「驗證並匯入 Excel」。也可從本機 `data/可上傳範例/` 選取同一份檔案。
2. v1 總量為 **447.141 tCO₂e**；v2 將 1 月用電增加 1,000 度、12 月增加 2,000 度，總量為 **448.551 tCO₂e**。匯入後可檢視前後值，回到左右工作台檢查每個數值及 Excel 工作表／列號。
3. 至「報告編輯與覆核」修改企業簡介、邊界、重大性說明及減量措施，按「儲存報告文字並更新草稿」。`{{total}}`、`{{cat:2}}` 等欄位會自動帶入計算結果，仍可在左右工作台點擊追溯。人工填寫的固定數字不會自動更新。
4. 完成三項覆核勾選、填寫覆核人，再按「確認並凍結本版，產生 PDF」。這是本機操作人之內部覆核紀錄，不代表第三方查證或身分認證。
5. 至「PDF 預覽與輸出」直接捲動閱讀整份文件、下載 PDF 及本版快照。PDF 依原始範本章節產生企業版報告，非對原始政府報告逐字逐頁覆寫。
6. 修改數據、匯入新版 Excel 或儲存新報告文字後，須重新覆核。舊 PDF 與快照保留於 `exports/<版本編號>/`，不會由新版本覆寫。

Excel 檔案包含四張底稿、使用說明及報告欄位對照；底稿排放結果由 Python 重算並與 Excel 數值核對。檔案內沒有公式、巨集或外部連線。

依目前授權，匯入僅接受本專案產生並列於 `data/可上傳範例/允許匯入清單.json` 的兩份原檔；先比對完整檔案 SHA-256，符合後才使用 openpyxl 讀取。修改或用 Excel 重新儲存後，雜湊通常會改變而遭拒絕。若要試算變動，可使用 v2 或在左右工作台修改數字。

每個凍結版本保存 PDF、盤查快照 JSON、覆核紀錄 JSON；若來自本專案 Excel，也保存原始 Excel。快照包含採用數值、文字、來源資訊、欄位對應、計算與範本版本及修訂紀錄。這是本機檔案留存，不是具身分驗證或防竄改機制的正式簽核系統。

### 檔案與資料留存

- `streamlit_app.py`：Streamlit 入口、頁籤、工作階段與匯出。
- `inventory.py`：計算邏輯、報告產生與明確的 metric ID → 底稿 row ID 對應。
- `components/audit_workspace/`：左右分欄、數值點擊、捲動定位及編輯互動；不依賴外部 CDN。
- `data/模擬盤查底稿.csv`：34 筆模擬活動資料，含用電、燃料、冷媒與差旅。CSV 以 UTF-8 BOM 編碼，可供 Excel 開啟。
- `generate_mock_data.py`：重建初始模擬底稿；檔案已存在時不覆寫。
- `excel_io.py`：自行產生 v1/v2 Excel、檔案允許清單、匯入驗證及 Excel 列號追溯。
- `workflow_ui.py`：匯入、文字編輯、覆核及 PDF 預覽操作。
- `report_export.py`：內容指紋、PDF 排版及本機版本快照。

尚未凍結的編輯保存在 Streamlit 工作階段，重新載入初始資料或結束工作階段後可能不再保留；已凍結的 PDF 與快照保存在本機 exports 資料夾。也可另行下載 CSV／JSON。此版未提供快照匯入、歷史版本列表、多人管理或資料庫。下載的報告 HTML 為靜態數值快照，點選追溯須在 Streamlit 內操作。

本案例僅示範部分排放源，未評估的類別不代表零排放。虛構憑證編號沒有對應實體檔；全部係數都是操作示範值，不可直接用於正式盤查。基準年、顯著性、完整性及查證所需內容仍待實際專案補齊。

## 既有瀏覽器原型

依 MVP 計畫製作的繁體中文瀏覽器原型，聚焦資料目錄、適用條件比較、決策覆核和來源版本追蹤。

## 開始使用

直接以瀏覽器開啟 `index.html`。不需安裝依賴或啟動伺服器。資料保存在目前瀏覽器的 `localStorage`；清除瀏覽器網站資料會一併清除原型資料。可從資料目錄和採用紀錄匯出 CSV 備份。

## 已實作

- 範例資料目錄，含活動數據、排放係數、排放強度、來源與適用欄位。
- 搜尋、類型與狀態篩選、資料新增與編輯。
- 比較兩筆資料；只有單位、氣體 / GWP、年度、地區、技術、活動定義和系統邊界欄位一致時才顯示百分比，並揭露公式及比較基準。
- 採用或排除紀錄、理由、覆核人、覆核日期和覆核狀態。
- 新來源版本及快照摘要；既有決策保存採用時的版本和值，不隨新版變更。
- 資料目錄和決策紀錄 CSV 匯出。

## 原型範圍

範例項目是介面展示資料，使用前應核對正式來源文件、版本和適用範圍。本版不連接外部資料庫、不提供多人權限或伺服器備份，也未加入 AI 文件擷取。瀏覽器本機儲存適合試用，不適合作為正式盤查檔案庫。工具提供資料整理與決策輔助，不判定符合法規或標準。
